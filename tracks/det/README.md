# Трек B: свой детектор и VLM-счётчик

Детектор `ft_yolo_v1` (YOLO11m, дообученный на aux-кадрах и псевдометках прод-детектора) работает на кропах столешниц ×4 и полном кадре. В финал вошли его руки. VLM-счётчик Qwen3-VL-4B даёт пять счётчиков по широкому кропу стола, в финал вошли вещи и руки.

| файл | что делает |
|---|---|
| `build_dataset.py` | датасет YOLO из `aux_boxes.csv` и прод-детекций с confidence от 0.6 на кадрах 27–28.10; 6 aux-кадров отложены для проверки |
| `train.py`, `tracks/det/configs/ft_yolo_v1.yaml` | обучение YOLO11m с COCO-весов, imgsz 1024, перевод в серый с вероятностью 0.3, сид 419 |
| `infer.py` | детекции на всех 1718 кадрах: свой детектор, COCO-детектор людей и посуды, запястья pose-модели |
| `post_hands.py` | правила «без людей нет рук» и «не больше двух рук на человека» для файла предсказаний |
| `vlm/run_vlm.py`, `vlm/prompts/vlm_v1.txt` | ответы Qwen3-VL-4B по строкам шардами и склейка шардов (`--merge`) |
| `vlm/eval_vlm.py` | качество VLM-счётчика на 231 train-строке |
| `fetch_weights.py`, `vlm/fetch_weights.py` | веса с закреплёнными файлами релиза или ревизией Hugging Face и проверкой sha256 |
| `common.py` | Ultralytics без сети, запись порциями с возобновлением, карточки артефактов |
| `kaggle/` | ноутбуки, которыми считались детекции, обучение и VLM, и [инструкция к ним](kaggle/README.md) |
| `experiments/` | разовые проверки: recall на отложенных aux-кадрах, пропуски людей, среднее рук двух версий, картинки для слайдов |
| `ERRORS.md` | типы ошибок прод-детектора по всем 39 train-кадрам |
| `REPORT.md` | результаты трека с числами |

Зависимости для GPU: `pip install -r requirements.txt -r tracks/det/requirements.txt`. Детекции и ответы VLM, на которых собран финал, лежат в `victimestsate/ts-artifacts-dets` и в выводе ноутбуков шардов, `tools/fetch_artifacts.py` скачивает их без пересчёта.
