# Ядро: сборка предсказаний

Здесь собираются предсказания из выходов всех источников. Сама логика лежит в библиотеке `ts/`, этот каталог содержит точки входа.

| файл | что делает |
|---|---|
| `build_pred.py` | собирает предсказание на 4964 строки по конфигу: train-строки out-of-fold по дням, тест с подгонкой на всём train |
| `base_calibrated.py` | бейзлайн организаторов в режиме calibrated, с out-of-fold train-строками для сравнения |
| `demo_queue.py` | очередь подсказок оператору по предсказаниям, `report/demo_queue.jpg` и `.csv` |
| `PEOPLE_ERRORS.md` | разбор ошибок по людям у бейзлайна и правило привязки людей к столам |
| `tracks/core/experiments/ov_and_counts.py` | счётчик чашек при согласии двух моделей трека C для отклонённого кандидата `CUPS_ov` |

Пример сборки: `python tracks/core/build_pred.py --name VLM_hands_avg --config configs/submissions/VLM_hands_avg.yaml`. `run.py` собирает тестовые строки тем же кодом `ts.stack` и пишет только сабмит.
